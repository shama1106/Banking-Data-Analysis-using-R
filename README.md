### ✔ Hypothesis Testing (Z-Test)

**Objective:** Test whether average house price differs from $1,000,000  

- H₀: μ = 1000  
- H₁: μ ≠ 1000  

**Results:**
- Z = -0.166  
- p-value = 0.868  

👉 Conclusion: No significant difference from $1,000,000 :contentReference[oaicite:5]{index=5}
